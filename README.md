# 纸上江南 · 水墨营造录

> **线上游玩**：https://yjj0339.github.io/ink-jiangnan/ （手机可直接打开）

在宣纸山水之间，营造一座欣欣向荣的江南小镇。纯前端水墨风模拟经营建造游戏，无任何依赖、无需安装。

![玩法](shots/02-desktop-grown.png)

## 玩什么

- **程序化山水**：河流游走、沃土沿河、林地矿脉成簇，每局地图皆不同（可「换一片山水」预览再开局）
- **产业链**：农田春种秋收、伐木采石采矿 → 木匠坊锻工具、纸坊抄纸、瓷窑烧瓷 → 商行/码头贸易生银
- **民生模拟**：人口增长、就业效率、幸福度、税赋五档、民宅三级升级（草屋→瓦房→楼阁）
- **科技树**：书院产研究点，农学/水利/造纸/制瓷/营造学/舟楫/医道/戏乐/算学/观星
- **四季与天灾**：春雨秋收冬藏；蝗灾、火灾、洪水、山贼、瘟疫……水井防火、望楼防盗、医馆防疫
- **任务链 + 15 成就**：从「筚路蓝缕」一路营造到「江南名镇」，功成名就放焰火
- **存档**：3 槽位 + 每岁自动存档 + 存档文件导出/导入

## 操作

拖动平移 · 滚轮/双指缩放 · 空格暂停 · 1/2/3 变速 · X 拆除 · Esc 取消。手机浏览器可玩（触屏点按建造，底部面板横滑）。

## 技术

纯原生 ES Modules + Canvas 2D，零依赖零构建。建筑、地形全部程序化矢量绘制（水墨低饱和 + 朱红点睛）。音效为 WebAudio 实时合成古筝拨弦。

```
npm run serve   # 本地试玩 http://localhost:8123
npm run sim     # 无头经济平衡模拟（闲置/普通/优化三剧本断言）
npm test        # Playwright 冒烟测试 + 截图
```
